# 最新资讯：日本房地产新闻抓取与多语言流程

按以下四步执行即可完成「抓取 → 概括 → 成页 → 多语言」。

---

## 第一步：抓取近三个月日本房地产新闻列表

- **接口**：`GET /api/news/google-rss-screened`
- **作用**：从 Google News RSS 抓取近三个月内与日本房地产相关的新闻，筛选掉人事任命、疑似付费墙等，得到列表。
- **输出**：列表写入 `data/rssSnapshot.json`，每条包含：**标题、时间、来源、链接**。
- **操作**：本地开发时访问  
  `http://localhost:3000/api/news/google-rss-screened`  
  或在部署环境调用该 API 一次。成功后即可进行第二步。

---

## 第二步：逐条查看正文并概括成一段文案

- **接口**：`GET /api/news/rss-dump`
- **作用**：读取 `rssSnapshot.json`，对每条新闻请求原文页面，提取正文并**概括成一段文案**（取首段或前约 400 字，按句号/段落断句）。
- **输出**：
  - `data/rssArticles.json`：每条保留标题、链接、日期、来源及正文摘要（text）。
  - `data/rssTranslations.json`：每条按 id 存**标题 + 概括文案**，并预填五语言键（zh、zh-TW、zh-HK、ja、en），便于第四步多语言。
- **操作**：在第一步完成后访问  
  `http://localhost:3000/api/news/rss-dump`  
  等待处理完成（会请求每条新闻的原文，耗时较长）。

---

## 第三步：将概括文案与来源链接做成网页并放入最新资讯

- **逻辑**（已实现，无需额外操作）：
  - 最新资讯列表：`/api/news/latest` 会读取 `rssSnapshot.json`，与站内静态资讯合并后返回；前端在「最新资讯」中展示。
  - 每条 RSS 新闻的详情页：`/news/rss/[id]` 从 `rssSnapshot.json` 取该条，再根据 id 从 `rssTranslations.json` 取**标题与概括文案**，页面上展示概括 + 「阅读原文」链接到新闻来源。
- **结果**：用户可在最新资讯中看到每条新闻，点进详情即看到概括文案和原文链接。

---

## 第四步：全部网页对应多语言

- **数据结构**：`data/rssTranslations.json` 中每条格式为：
  ```json
  {
    "<id>": {
      "title": { "zh": "...", "zh-TW": "...", "zh-HK": "...", "ja": "...", "en": "..." },
      "summary": { "zh": "...", "zh-TW": "...", "zh-HK": "...", "ja": "...", "en": "..." }
    }
  }
  ```
- **当前**：第二步完成后，各语言会先填入**同一份原文**（标题 + 概括文案），页面已能按语言切换显示对应键。
- **完善多语言**：将各语言的 `title`、`summary` 改为对应语言的翻译即可（可手动编辑 `rssTranslations.json`，或用翻译 API/工具批量生成后写入）。前端会根据当前语言自动取用。

---

## 推荐执行顺序

1. 调用 **第一步** API → 生成/更新 `rssSnapshot.json`  
2. 调用 **第二步** API → 生成 `rssArticles.json` 与 `rssTranslations.json`  
3. 打开首页或「最新资讯」→ 列表与详情页自动使用上述数据  
4. 按需编辑 `rssTranslations.json` 中各语言的 `title`、`summary`，完成多语言
