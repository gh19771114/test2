# 最新资讯 · 日本房地产新闻抓取与发布流程

按以下四步执行，即可把近三个月日本房地产相关新闻抓取、概括、做成站内页并支持多语言。

---

## 第一步：抓取列表（标题、时间、来源、链接）

- **接口**：`GET /api/news/google-rss-screened`
- **作用**：从 Google News RSS 抓取近三个月内与日本房地产相关的新闻，筛掉人事任命、疑似付费墙等，得到列表。
- **输出**：`data/rssSnapshot.json`，每条约定字段：`title`、`date`、`source`、`link`。

**操作**：本地开发时访问  
`http://localhost:3000/api/news/google-rss-screened`  
或部署后访问对应域名下的同一路径。执行一次即可更新列表。

---

## 第二步：逐条抓正文并概括成一段文案

- **接口**：`GET /api/news/rss-dump`
- **前提**：已执行第一步，存在 `data/rssSnapshot.json`。
- **作用**：按快照中的链接依次请求每条新闻正文，提取纯文本，再概括成一段文案（首段或前约 400 字，按句号/段落截断）。
- **输出**：  
  - `data/rssArticles.json`：每条含正文摘要等；  
  - `data/rssTranslations.json`：每条对应多语言键下的标题与概括文案（初始为同一原文，供第四步翻译）。

**操作**：在第一步完成后访问  
`http://localhost:3000/api/news/rss-dump`  
（或部署后的同路径）。建议在终端用 `curl` 调用，避免浏览器超时。

---

## 第三步：把概括文案和来源链接做成网页，放入「最新资讯」

- **逻辑**（已实现，无需额外操作）：  
  - 最新资讯列表：`/api/news/latest` 会优先读取 `data/rssSnapshot.json`，把其中条目与站内静态资讯合并，列表里每条可点击进入详情。  
  - 详情页：`/news/rss/[id]` 从快照中取该条，展示「概括文案」和「原文链接」；标题与概括文案来自 `data/rssTranslations.json`（当前语言由站点语言切换决定）。

只要第一步、第二步已跑过，列表和详情都会自动使用上述数据，无需再配置。

---

## 第四步：多语言对应（已自动化）

- **数据**：`data/rssTranslations.json`  
- **结构**：按每条新闻的 id 存 `title`、`summary`，每个字段下按语言键分：`zh`、`zh-TW`、`zh-HK`、`ja`、`en`。
- **自动翻译**：运行一键脚本 `pnpm run crawl-news`（或 `node scripts/crawl-news.mjs`）时，会在第二步完成后自动调用免费翻译 API（MyMemory），将日文标题与摘要翻译为简体中文、英文、繁体中文（台/港），并写回 `rssTranslations.json`。无需手动编辑。
- **说明**：免费 API 有每日请求/字数限制；若条数很多可能部分未翻译，可再次运行脚本或手动补全该 JSON。

---

## 建议执行顺序（一键完成）

1. 启动开发服务器：`pnpm run dev`（或 `npm run dev`）。  
2. 在项目根目录执行：**`pnpm run crawl-news`**（或 **`node scripts/crawl-news.mjs`**）。  
   - 脚本会依次执行：第一步（抓列表）→ 第二步（抓正文并概括）→ **第四步（自动翻译多语言）**。  
3. 打开站内「最新资讯」列表与各条详情页，即可看到已抓取并带多语言标题/摘要的新闻。
